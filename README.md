# Portfólio do Antony

Abra o `index.html` no navegador (precisa de internet para o Bootstrap e a fonte).

## Publicar de graça (GitHub Pages)
1. Crie um repositório público no GitHub (ex.: `portfolio`).
2. Envie todos os arquivos desta pasta (index.html, style.css, script.js, foto.jpg, favicon.svg).
3. Em Settings > Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)` e salve.
4. Em alguns minutos o site fica em `https://antonydias425-tech.github.io/portfolio/`.
